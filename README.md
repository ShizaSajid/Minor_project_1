# Group DNA 🧬💬

**Group DNA** is a Python-based WhatsApp Chat Analyzer that transforms exported WhatsApp chat files into meaningful insights about group activity, participant behavior, and personality archetypes.

## ✨ Features

- 📂 Parse exported WhatsApp chat files
- 📊 Generate chat statistics and participant insights
- 📅 Analyze daily and hourly activity
- 📈 Identify the busiest days and active hours
- 💬 Word frequency analysis
- ⏱️ Response time analysis
- 🌙 Night activity detection
- 👻 Silent streak analysis
- 🎭 Personality archetype detection, including:
  - The Spammer
  - The Group Mom
  - The Night Owl
  - The Storyteller
  - The Drama Queen
  - The Ghost
  - The Question Master

## 🛠️ Built With

- Python
- Google Colab
- NumPy
- datetime
- File Handling
- Dictionaries, Lists, Sets & Strings

## 🚀 How to Use

1. Export a WhatsApp chat **without media**.
2. Upload the `.txt` file to the notebook.
3. Run all cells.
4. View chat analytics and personality insights.

## 📌 Project Goal

The goal of **Group DNA** is to demonstrate how Python and data analysis can uncover interesting behavioral patterns and communication insights from everyday WhatsApp conversations.
